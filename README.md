# CollegeDunia — L1 Lead Qualification CRM

Meritto-style CRM for CollegeDunia institute accounts.

## Run

```bash
cd unified_view_dashboard
npm install
npm run dev
```

## Flow

1. Admin — select institute user → Open dashboard  
2. Campaigns — add campaign, upload CSV, open lead list  
3. Run Campaign — Email / SMS / WhatsApp / Voicebot  
4. Voicebot — type selection, run, lead cards with status, attempts, recordings, archive
