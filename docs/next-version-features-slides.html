Feature 1

User Management

Today only an open Admin institute picker exists. Next version introduces login + three roles: Admin (CollegeDunia), User (the institute itself, 1:1), and Agent (campaign runner on granted channels only).

Agents can upload leads, run campaigns, and view analytics on allowed channels — they cannot see spend, archive, or pause/resume. No admin impersonation in this release.

Admin

CollegeDunia

Create Users, set institute-allowed channels, manage agents and grants.

User

Institute = User

Full client dashboard: all channels, expense, pause/archive, manage agents.

Agent

Channel operator

Only granted channels; primary job is running campaigns.

Feature 2

Working SMS, Email & WhatsApp

SMS, Email, and WhatsApp already share the Voicebot ChannelWorkspace UI (campaigns, upload CSV, analytics, leads) but Run Campaign is hidden and there is no send backend — only Voicebot pushes to Convin today.

Next version enables Run on these channels with the same CRM screens, modals, KPIs, and lead lifecycle — so messaging works like Voicebot without inventing a separate product UI.

  • Same list → create → upload → Run → Outcome · Analytics → Detailed · lifecycle
  • Run modal mirrors Voicebot type picker (B.Tech / MBBS / MBA / Online Courses)
  • Attempts use sms / email / whatsapp message counters; no Recording column

Feature 3

NPF data + select leads to churn

Meritto / NPF lead data (Primary · Secondary · Tertiary, Paid / Submitted applications, enrolment, instance, campaign origin) is reflected on the CollegeDunia dashboard and All Leads — same CRM shell, NPF fields and KPIs.

Users multi-select leads (e.g. form filled but admission incomplete, window closing) and churn via any channel as Reminder, Application form, or Follow-up — then push into the existing channel campaign Run flow.

Example

Student filled the form, paid or submitted, but did not enrol. Select those Primary leads → Reminder → SMS/WhatsApp/Email/Voicebot → send before the window closes.

Fits current CRM

Extends All Leads / Dashboard filters and the existing RunLeadPicker + ChannelWorkspace Run pattern — not a separate Meritto clone.

Summary

One-line takeaways

  • User Management — Role-based Admin / User / Agent access so institutes and channel agents use the CRM safely.
  • Messaging channels — SMS, Email, WhatsApp become runnable inside the same campaign workspace as Voicebot.
